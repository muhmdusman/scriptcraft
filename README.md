## 🚀 Quick Start

### Option 1: Use Online (Recommended)
Visit [ScriptCraft](https://scriptcraft.app) and start converting text immediately. No installation required!

### Option 2: Run Locally

```bash
# Clone the repository
git clone https://github.com/muhmdusman/scriptcraft.git

# Navigate to directory
cd scriptcraft

# Install dependencies
npm install

# Start local server
npm run dev
```

Visit `http://localhost:3000` in your browser.

## 📖 Usage

1. **Enter your text** in the input area
2. **Customize** font, size, spacing, colors (optional)
3. **Click "Generate Image"** to create handwritten version
4. **Download** individual images or export as PDF

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (ES6 Modules)
- **Styling**: Modern CSS with CSS Variables
- **Canvas Rendering**: [html2canvas](https://github.com/niklasvh/html2canvas)
- **PDF Generation**: [jsPDF](https://github.com/MrRio/jsPDF)
- **Testing**: [Cypress](https://github.com/cypress-io/cypress)
